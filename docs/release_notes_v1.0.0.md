# Release Notes: v1.0.0

Date: 2026-05-02

This release is the journal-disclosure code snapshot for the US-Brazil birth registry analysis.

## Scope

- Public-data download and harmonisation workflow for US NCHS natality files and Brazil DATASUS/SINASC data.
- Reproducible R scripts for primary models, sensitivity analyses, grouped-count validation, and output preparation.
- Statistical analysis plan, data-source notes, and variable harmonisation documentation.

## Exclusions

This release intentionally excludes manuscript files, cover letters, response files, generated figures and tables, submission packages, raw registry microdata, interim datasets, and harmonised individual-level analytic files.

## Archiving

The `v1.0.0` tag can be linked to Zenodo, OSF, or another persistent repository to mint a DOI if required by the journal.

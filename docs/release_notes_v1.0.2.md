# Release Notes: v1.0.2

This release synchronises final terminology and reviewer-facing supplementary-table formatting used in the submission package.

## Changes

- Renamed the missingness output for prenatal visit count from a care-oriented internal label to `prenatal_visit_count_unknown_pct`.
- Kept backward-compatible display mapping for any older missingness files that still contain `prenatal_care_unknown_pct`.
- Reworded supplementary-table notes from compressed `excluding-2024` terminology to `models excluding 2024 births`.

## Scope

These updates are terminology and reporting-format changes only. They do not alter source data, exposure definitions, outcome definitions, modelling specifications, adjustment sets, or numerical results.
